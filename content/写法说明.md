# 写法说明

页面上的所有文字都在这个文件夹里。改完保存、推到 GitHub，刷新页面就能看到。代码不用碰。

## 文件对应哪里

- `iris/资料.md`、`aurelia/资料.md`：资料页
- `iris/故事.md`、`aurelia/故事.md`：故事页
- `iris/学院制服.md`、`aurelia/学院制服.md`：穿上北方学院制服后的资料和秘闻
- `iris/倒吊人.md`：绞索 + 白布解锁后的资料和秘闻
- `词条/`、`物品/`、`秘闻/`：点开后在资料框里读的长文，文件名就是标题
- `台词.md`：卡槽、贴纸、Aurelia 被戳到时说的话
- `家族/`：王室与家族页（点左上角 HELIOS 进入）
- `省份/`：王室与家族页地图模式里的省份

## 资料页

开头 `---` 之间的三行是头衔、出身和数据：

    role: ex 情报部部长 · 首都学院哲学教授
    place: Enore 省 · 背靠群山的小镇
    stats: 172cm / 45kg / 清瘦 | INTJ / 混乱中立

`·` 分开头衔，`/` 分开数据，`|` 是中间那道竖线。

下面每个 `## 标题` 是一个小节，标题写什么，页面上就显示什么（比如「遗物」）：

- 一行一行的文字：照原样一行一行显示
- `1.` `2.` 开头：编号列表
- `-` 开头：用 · 连成一行

## 故事页、秘闻

- `## 人物关系`：每行 `- 名字：描述`。名字写成 `[[Aurelia]]`，点了就跳到她的页面
- `## 事件`：每行 `- 14 岁：发生了什么`
- `## 秘闻`：每行 `- 关于什么：内容`。末尾加 `→ [[那个冬天]]`，就会出现「阅读更多」（要先揭开黑块才浮出来）

穿衣服的文件（学院制服、倒吊人）把两页写在一起：`# 资料` 下面是资料页，`# 秘闻` 下面是秘闻页。

## 王室与家族（`家族/`）

点人物页左上角的 HELIOS 进入这一页。每一家一个文件：`Helios.md`、`Varn.md`、`K.md`、`Daeris.md`、`Solenne.md`、`Filippou.md`、`南方家族.md`。颜色、家徽图案和地图上的位置在代码里，其余文字都在这里。

开头 `---` 之间：

    name: Daeris
    zh: 东方                       （地域圆盘上名字下面的小字）
    badge: 五家之首                 （名字下面的小标签，可以不写）
    fallen: 是                     （已倒台的家族才写，线变虚线）
    region: 东方 · 补充             （` · ` 后面是小字）
    party: 首都派 · 建制内的自由派   （同名党派会自动连成一根横杠）
    cabinet: 司法 · the Long Hand
    crown: 母族 · 已故王后           （写 母族 / 联姻 / 血缘 的会画成金线）
    head: Gauvin（Aurelia 登基后）   （没有就写 待定）
    talents: 5 / 5 / 3 / 2 / 2 / 1  （血统 / 王眷 / 财富 / 兵戈 / 学识 / 暗面）
    since: Ostrium                 （传承从哪个时代开始：Solenar、Ostrium、第一王朝、第二王朝、家族时代、Helios）
    lineage: Ostrium 时代的贵族      （传承旁边的小字）

下面的小节，标题要照写：

- `## 家训`：翻开牌后最上面那句
- `## 一句话`：家徽页牌桌上方那句
- `## 简介`：翻开牌后右下角那段（鼠标移开天赋时显示）
- `## 起源`、`## 家风`：翻开牌后右边的文字
- `## 立场`：每行 `- 家族名：血亲 / 盟 / 仇 / 和`
- `## 家族与文化`、`## 与王室`（Helios 写 `## 继承`）、`## 人物`、`## 秘闻`：结构页右边的资料卡；`## 人物` 每行 `- 名字：描述`

## 省份（`省份/`）

地图模式里的省份。`目录.md` 按地区列出所有省份，顺序就是页面上的顺序。每个省一个文件，文件名就是省名；新增一个省，在目录里加一行、放一个同名文件（省界要找我画）。

开头 `---` 之间：

    name: Velmar
    role: K 的本家 · North          （名字下面那行，` · ` 分开）
    faith: 教会遍地，约八成信教       （信仰，可以不写）
    living: 麦田 · 庄园              （生计，可以不写）
    port: 是                        （有港口才写，地图上印锚）
    at: 361, 321                    （在地图上的位置）
    label: 382, 377                 （名字印在哪里，和 at 一样就不用写）
    capital: 是                     （王都才写）
    palace: -34, 0                  （名字上方摆一座宫殿模型，数字是偏移）
    towns: kloria · 739, 98 · 港口   （省里另外标出的城镇，几个就用 / 分开）
    camps: 895, 95 / 952, 128       （牧民营地的小帐篷）

下面的小节：

- `## 简介`、`## 风貌`、`## 民风`：照写
- `## 旧事`：`1.` `2.` 开头，一条一件事
- `## 局势`：席位下面那段，鼠标不在席位上时显示
- `## 席位`：每行一个席位，没有这个席位就不写那一行

      - 总督：K，Varn 也在｜理由
      - 兵戈：摇摆：Varn / Filippou｜理由
      - 教会（主教座）：Varn
      - 商会：五大家族之外

  第一个家族为主（地图上上色），写「也在」的是也在；`摇摆：` 后面是互相拉扯、没有一家为主；`五大家族之外` 是哪家都没有。家族写 `家族/` 里的名字，王室写「王室」。`｜` 后面是鼠标移到席位上时显示的理由，可以不写。席位名：总督、兵戈、教会、学院、商会、保民官、Mage。

省界、地形和水色是 `map/` 里的图，不在这里改。

## 通用写法

- `【这里】`：黑块，悬停才显示
- `【!这里】`：黑块，而且会戳到 Aurelia（她会打断你）
- `[[北方内战]]`：链接到词条；`[[生日宴闹剧|生日宴]]`：显示「生日宴」，点开「生日宴闹剧」
- 词条正文里，`> ` 开头是引文，单独一行 `·` 或 `...` 是分隔
- 词条开头可以写 `tag:`（标题上方的小字）、`desc:`（斜体导语）、`style: scene`（小说字体）
